Ship tees to the customer (not your house)

The website + Stripe Payment Link collect payment, size/color/qty, email, and the customer’s shipping address. You copy that address into Printful/Printify so the package goes straight to them.

1. One-time Stripe Payment Link setup

  1. Stripe Dashboard → Product catalog → create TYL Focus Tee ($34.99).
  2. Create a Payment link for that product.
  3. Turn ON: Collect customers’ shipping addresses (required).
  4. Turn ON: Collect phone numbers (recommended for carriers).
  5. Optional: Custom fields → add Size (dropdown S / M / L / XL / XXL).
  6. Optional: enable Adjustable quantity.
  7. After payment → Don’t show confirmation page → Redirect to:
    https://YOUR-LIVE-DOMAIN/apparel-thanks.html
  8. Paste the Payment Link URL into tyl-ai-landing/site.js (APPAREL_STRIPE_PAYMENT_LINK) or set before load: 
    <script>window.TYL_APPAREL_STRIPE_LINK = "https://buy.stripe.com/…";</script>

If shipping address collection is off, Stripe will not give you a customer address and you cannot ship direct-to-buyer from this flow.

2. What the website already sends

When the buyer clicks Buy now, Stripe opens with:

  • prefilled_email — buyer email from the apparel form
  • prefilled_quantity — qty from the apparel form
  • client_reference_id — compact ticket, e.g. TYL-TEE|CREAM|M|Q1|you@email.com

Name, email, color, size, and qty are also saved in the browser for the thanks page. The shipping street address only exists in Stripe (and later in your print order).

3. After each sale — fulfillment checklist

  1. Open Stripe → Payments.
  2. Open the new payment.
  3. Copy from the payment page:
    • Shipping name
    • Address line 1 / line 2
    • City, state/region, postal code, country
    • Phone (if collected)
    • Email
    • Client reference → parse color, size, qty (and Size custom field if present)
  4. Open Printful or Printify → Manual order / Create order.
  5. Recipient = Stripe shipping details (NOT your home address). Confirm the ship-to fields match Stripe exactly.
  6. Item = TYL Focus Tee · match size + color + qty from the reference id.
  7. Submit / confirm the print order. Save the provider order ID next to the Stripe payment id.
  8. When tracking appears, email the buyer (or rely on Printful’s customer notifications if enabled).

5. Decode client_reference_id

Format from the website:

TYL-TEE|CREAM|LWHITE|M|Q2|buyer@email.com
  • TYL-TEE — product family
  • CREAM — shirt color (also Black, Pink, etc.)
  • LWHITE / LBLACK — logo/design ink
  • M — size
  • Q2 — quantity
  • email — buyer contact

Any shirt color can be fulfilled with a white or black logo/design — match both fields when placing the print order.

6. Avoid shipping to yourself

  • Never use your home/business as the Printful recipient unless the order is a personal sample.
  • In Printful/Printify, double-check the recipient block before confirming.
  • If Stripe shipping is missing, refund or email the buyer for an address before ordering a print.
